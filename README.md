# Library
https://samiam120.github.io/Library/

Library/Book Log implemented with HTML, JS, CSS

Designed and implemented a dynamic library management application using JavaScript, enabling users to log, manage, and update book entries.

Applied object-oriented programming principles with a custom Book constructor and prototype methods for functionality such as toggling read status.

Built interactive and responsive UI components by dynamically generating elements and managing state with an in-memory library array.

Integrated input validation and user feedback mechanisms to ensure a seamless user experience.

Demonstrated expertise in DOM manipulation, event-driven programming, and scalable component design to create a clean and functional interface.
